
# -Actividad-Semana-9

Este proyecto contiene ejercicios básicos de Node.js:
- Manejo de variables y tipos.
- Estructuras condicionales y ciclos.
- Uso de módulos (import/export).
- Manipulación de archivos con el módulo 'fs'.

## Cómo ejecutar
Para probar los ejercicios, usa el comando `node` seguido del nombre del archivo. Ejemplo:
`node app.js`
